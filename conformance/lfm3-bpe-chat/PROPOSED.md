Decisions for the reviewer:

1. Accept these as development fixtures for the `lfm3-bpe-chat` profile.
2. `--truncate 16` is chosen to exercise truncation on many cases, not the model's 256K-token context.
3. The corpus has no case with the LFM3 tool-call tags (`<tool_call>`, `<function=`, `<parameter=`, which are non-special added tokens). A corpus file with those cases would come in a separate pull request; until then the profile lists `added_tokens_special_and_non_special_in_text` as experimental.
