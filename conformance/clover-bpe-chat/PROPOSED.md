This is the tokenizer of the Clover-35B-A3B-Preview model request in starlinghq/starling. Clover is a block-diffusion fine-tune of `Qwen/Qwen3.6-35B-A3B`. Its file is the Qwen2/Qwen3 pipeline (the `qwen2-bpe-kev` regex, without `\p{M}`) with one change: vocabulary id 151669 is the special added token `<|mask|>`, the diffusion mask, in place of `ĠãģĿãĤĮ` (" それ"), and the 6 merges that built that token are removed. The post-processor is `ByteLevel` alone, so it adds no tokens.

```sh
python -I reference/tokenizer-json/run_tokenizer_json.py --profile clover-bpe-chat \
    --asset .models/Diffuspace/Clover-35B-A3B-Preview/4b0402b65e523d0183a14c431955438714cb16ff/tokenizer.json \
    --corpus conformance/corpus/tokenizer-corpus-v1.jsonl \
    --corpus conformance/corpus/tokenizer-corpus-qwen-bpe-v1.jsonl \
    --out conformance/clover-bpe-chat --truncate 16 --without-special-tokens \
    --batch empty,ascii-sentence,chinese,emoji-zwj,bpe-special-adjacent,bpe-code-python \
    --pair-batch pair-ascii,pair-multilingual,pair-empty-second,bpe-pair-special \
    --pad-token '<|endoftext|>'
```

Decisions for the reviewer:

1. Accept these as development fixtures for the `clover-bpe-chat` profile.
2. `--truncate 16` is chosen to exercise truncation on many cases, not the model's 128K-token context.
3. The corpus has no `<|mask|>` case and no text that the removed merges would have joined. A corpus file with those cases would come in a separate pull request; until then the profile lists `added_tokens_special_and_non_special_in_text` and `added_token_with_vocabulary_id` as experimental.
