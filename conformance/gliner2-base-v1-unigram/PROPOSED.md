# Accepted fixtures

Status: accepted as development fixtures by Mark on 2026-10-08 (PR #4). Not a release evaluation set: the corpus was written by an agent; the protected release set is P-030. The decisions below were taken as proposed.

Tokenizer fixtures for GLiNER2's per-word input encoding. No GLiNER2 manifest exists yet; the checkpoint and feature contract are open decisions (`docs/kickoff.md`).

Generated by `model-pipeline/reference/gliner2/run_gliner2_tokenizer.py` and `model-pipeline/reference/compare_tokenizers.py` at repository commit `001ced60d8d3f843168f97efc3f247495bdb97e2`, from `fastino/gliner2-base-v1` at `f9634218e53580c56edf0de97ca1a7d3f1c2354e` with GLiNER2 source at `55656fbfa01d3d4a77485e1a1eeeaf682990ccdf` (transformers 4.57.6, tokenizers 0.22.2), on corpus `model-pipeline/reference/corpus/tokenizer-corpus-v1.jsonl`.

| File | Contents |
| --- | --- |
| `gliner2-tokenizer.jsonl` | Per case: normalized text (GLiNER2 appends `.`), lower-cased words with offsets in three units, per-word subwords from the fast tokenizer, full input ids for an entity schema `[person, location]`, word and schema routing positions. CJK and Thai cases also carry the `char` word splitter. |
| `gliner2-fast-vs-slow.json` | Per-word differences between `DebertaV2TokenizerFast` (what GLiNER2 loads) and `DebertaV2Tokenizer` (SentencePiece). 11 of 46 cases differ. |
| `tokenizer-implementations.transformers-4.json` | Whole-text encodes (with `[CLS]`/`[SEP]`) from transformers 4.57.6 fast and slow and raw SentencePiece, wherever they differ from the checkpoint's `tokenizer.json`. |

Decisions for the reviewer:

1. The reference is the fast tokenizer, because GLiNER2 loads it. Slow-tokenizer parity would be unsupported (byte fallback, zero-width characters, Hangul jamo, and Unigram tie-breaking all differ).
2. The schema in these fixtures is one entity schema. Other schema kinds (classification, relations, structures) change only the schema prefix and need their own cases when the feature contract is set.
